# T.A.S.T.E. FOUNDATION Website

This repository contains the official Hugo-based website for T.A.S.T.E. FOUNDATION CORPORATION, including:

- Homepage
- About page
- Historical Origins (Trans-Atlantic Slave Trade Expedition)
- Programs (Community Garden, Aquaponics, Housing, Youth Empowerment)
- News & Updates
- Donate page
- Volunteer page
- Contact page

The site is built using the Hugo static site generator and deployed through Cloudflare Pages.
